## What Is a Microcontroller?

- 일반 컴퓨터는 CPU, RAM, ROM, 주변 장치가 버스를 통해 연결된 구조
- Microprocessor는 컴퓨터의 연산과 제어를 담당하는 CPU를 하나의 IC에 집적한 칩
  - RAM, ROM, I/O 장치는 외부에 연결
- Intel과 AMD의 x86, Arm Cortex 계열 등이 processor의 예
- Microcontroller는 CPU, RAM, ROM 또는 Flash, I/O, timer 등을 하나의 칩에 통합한 장치
- MCU는 Micro-Controller Unit의 약칭이며 하나의 칩으로 구성한 컴퓨터
- 일반적인 범용 microprocessor보다 처리 능력은 낮은 편이며 특정 응용에 맞춘 설계
- 특정 기능을 수행하는 firmware를 비휘발성 메모리에 저장함.
- 작은 크기, 낮은 가격과 전력 소모가 중요한 응용에 적합함.

## Microcontrollers Are Everywhere

- 가정용 기기의 알람 시계, 공유기
- 사무용 기기의 스캐너, 프린터, 팩스, 복사기
- 산업용 기계, 장비, 계측기와 로켓
- 장치 내부에서 특정 기능을 담당하는 embedded system의 핵심 구성 요소
