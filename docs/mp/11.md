# 11. Timer and GPIO

## Topics

- Peripheral interfacing
- Timer, input capture, output compare 및 PWM
- GPIO의 memory map과 입출력 방식

## Interfacing Peripherals

- I/O device는 CPU와 통신하는 register interface 및 외부 신호를 처리하는 I/O mechanism으로 구성
- UART의 CPU 측 interface는 status, data, control register로 구성
- UART 내부의 송수신 회로와 baud rate generator가 serial port 신호 처리
- CPU는 register를 읽고 쓰며 내부 I/O mechanism의 세부 동작과 분리됨.

## I/O Devices

| 방식 | Register 접근 | Instruction |
| --- | --- | --- |
| Port-mapped I/O | 별도 port 주소 공간 | 전용 I/O instruction |
| Memory-mapped I/O | Processor의 memory 주소 공간 | 일반 `LDR`, `STR` |

- Memory-mapped I/O에서는 각 device register에 주소 할당
- 예를 들어 GPIO Data Output Register에 `STR`을 실행하면 GPIO output pin의 값 변경

## ARM Memory-Mapped I/O

```asm
.equ DEV1, 0x40010000
LDR  r1, =DEV1
LDRB r0, [r1]
MOV  r0, #8
STRB r0, [r1]
```

- `r1`에 device 주소 구성, `LDRB`로 byte 읽기, `STRB`로 byte 기록

```c
#define DEV1 0x40010000
Var1 = *(char *)DEV1;
*(char *)DEV1 = Var1;
```

- C의 pointer dereference도 해당 memory 주소의 device register 접근

## Timer

- Timer는 processor의 실행과 독립적으로 증가하는 free-running counter
- Input capture, output compare 및 PWM 생성에 활용

## Timer: Clock

- Prescaler `PSC`가 입력 clock `f_CL_PSC`를 counter clock `f_CK_CNT`로 분주
- Auto-Reload Register인 `ARR` 값까지 센 뒤 counter reload
- Timer event에서 interrupt 발생 가능

$$$
f_{CK\_CNT}=\frac{f_{CL\_PSC}}{PSC+1}
$$$

- Upcounting에서 `0`부터 `ARR`까지 세면 한 주기는 `(ARR+1)`개의 counter clock

## Input Capture

- 외부 event가 발생한 순간의 timer counter 값을 Capture/Compare Register인 `CCR`에 저장
- 저장한 count 값으로 event 발생 시점이나 두 event 사이의 시간 측정

## Output Compare

- Counter `CNT`와 `CCR`을 비교해 일치할 때 output reference인 `OCREF` 변경 가능
- Compare event를 interrupt의 근거로 사용 가능

| Output Compare Mode `OCM` | `OCREF` 동작 |
| --- | --- |
| `000` | Frozen, 출력 유지 |
| `001` | `CNT == CCR`일 때 high |
| `010` | `CNT == CCR`일 때 low |
| `011` | `CNT == CCR`일 때 toggle |
| `100` | 항상 low |
| `101` | 항상 high |

## PWM Generation

| Mode | `CNT < CCR` | `CNT >= CCR` |
| --- | --- | --- |
| PWM mode 1 | Active | Inactive |
| PWM mode 2 | Inactive | Active |

- Upcounting에서 PWM mode 1은 `CNT < CCR`일 때 high, 그 밖에는 low인 예
- PWM mode 2는 같은 조건에서 low, 그 밖에는 high인 예

## PWM Mode 1

- `ARR = 6`, `CCR = 3`이면 counter는 `0–6` 반복
- `CNT = 0, 1, 2`에서 high, `CNT = 3, 4, 5, 6`에서 low

$$$
T_{period}=(ARR+1)T_{clock}=7T_{clock}
$$$

$$$
D=\frac{CCR}{ARR+1}=\frac{3}{7}
$$$

## PWM Mode 2

- `ARR = 6`, `CCR = 3`이면 `CNT = 0, 1, 2`에서 low, `CNT = 3–6`에서 high

$$$
D=1-\frac{CCR}{ARR+1}=\frac{4}{7}
$$$

- `CCR = 5`로 바꾸면 `CNT = 0–4`에서 low, `CNT = 5, 6`에서 high

$$$
D=1-\frac{5}{7}=\frac{2}{7}
$$$

- 두 경우 모두 period는 `7T_clock`

## General Purpose Input/Output (GPIO)

- STM32L4의 GPIO port는 `A–H`의 여덟 개
- 각 port에는 최대 `16`개의 pin 존재

## Red LED (PB.2)

- STM32L4 Discovery Kit의 red LED가 `PB.2`에 연결
- `PB.2 = 1`이면 red LED on, `PB.2 = 0`이면 off
- 그림에는 `PE.8`의 green LED도 표시

## GPIO Ports

- ARM Cortex-M4 core의 bus matrix가 Flash, SRAM 및 peripheral bus에 연결
- `GPIOA–GPIOH`는 memory-mapped peripheral로 접근
- UART, SPI 및 Timer도 peripheral bus를 통해 연결

## Basic Structure of a GPIO Port Pin

- Pin의 output 경로는 output data register와 output driver로 구성
- Input 경로는 Schmitt trigger와 input data register로 구성
- Mode, output type 및 pull-up/pull-down register로 pin 동작 설정

## GPIO Memory Map (STM32L4)

| 주소 영역 | 크기 | 용도 |
| --- | --- | --- |
| `0x00000000–0x1FFFFFFF` | `0.5 GB` | Code |
| `0x20000000–0x3FFFFFFF` | `0.5 GB` | SRAM |
| `0x40000000–0x5FFFFFFF` | `0.5 GB` | Peripheral |
| `0x60000000–0x9FFFFFFF` | `1 GB` | External RAM |
| `0xA0000000–0xDFFFFFFF` | `1 GB` | External device |
| `0xE0000000–0xFFFFFFFF` | `0.5 GB` | System |

| GPIO port | 시작 주소 | 할당 공간 |
| --- | --- | --- |
| `GPIOA` | `0x48000000` | `1 KB` |
| `GPIOB` | `0x48000400` | `1 KB` |
| `GPIOC` | `0x48000800` | `1 KB` |
| `GPIOD` | `0x48000C00` | `1 KB` |

- 각 GPIO register의 폭은 `4` bytes

| Port 시작 주소 기준 offset | Register |
| --- | --- |
| `0x00` | `MODER` |
| `0x04` | `OTYPER` |
| `0x08` | `OSPEEDR` |
| `0x0C` | `PUPDR` |
| `0x10` | `IDR` |
| `0x14` | `ODR` |
| `0x18` | `BSRR` |
| `0x1C` | `LCKR` |
| `0x20` | `AFR[0]` |
| `0x24` | `AFR[1]` |
| `0x28` | `BRR` |
| `0x2C` | `ASCR` |

## GPIO Output

- `MODER`는 pin당 `2` bits로 input `00`, output `01`, alternate function `10`, analog `11` 선택
- `OTYPER`는 pin당 `1` bit로 push-pull `0` 또는 open-drain `1` 선택
- `PUPDR`는 pin당 `2` bits로 none `00`, pull-up `01`, pull-down `10`, reserved `11` 선택
- `ODR`는 하위 `16` bits가 pin별 output data, 상위 `16` bits는 reserved

## GPIO Mode Register (MODER)

- `32`-bit register에 `16`개 pin의 `2`-bit mode field 배치
- `PB.2`의 field는 bit `5:4`

```c
GPIOB->MODER &= ~(3UL << 4);
GPIOB->MODER |=  1UL << 4;
```

- 먼저 두 bit를 지우고 `01`을 기록해 `PB.2`를 output으로 설정

## GPIO Output Data Register (ODR)

```c
GPIOB->ODR |= 1UL << 2;
```

- Bit `2`를 `1`로 설정해 `PB.2`에 high 출력

## GPIO Output Type Register (OTYPER)

```c
GPIOB->OTYPER &= ~(1UL << 2);
```

- Bit `2`를 `0`으로 설정해 `PB.2`를 push-pull output으로 선택

## GPIO Output: Push-Pull

- Output driver는 상단 PMOS와 하단 NMOS로 구성
- Output bit가 `1`이면 PMOS를 통해 pin을 `VCC`로 구동하고 외부 회로에 current 공급
- Output bit가 `0`이면 NMOS를 통해 pin을 ground로 구동하고 외부 회로의 current 흡수

## GPIO Output: Open-Drain

- Output driver가 하단 NMOS만 사용
- Output bit가 `0`이면 NMOS가 켜져 pin을 ground로 구동하고 current 흡수
- Output bit가 `1`이면 NMOS가 꺼져 pin이 floating, 즉 high-impedance `HiZ` 상태
- High 신호가 필요하면 외부 pull-up resistor 사용
- 여러 open-drain device가 output bus를 공유할 때 하나라도 low로 구동하면 bus는 low
- 모든 device가 floating이면 pull-up에 의해 bus가 high

## GPIO Input

- Input pin의 Schmitt trigger가 noise에 의한 불안정한 전환 완화
- `IDR`의 하위 `16` bits가 pin별 input value, 상위 `16` bits는 reserved
- 외부 입력이 `HiZ`이면 pull-down은 유효한 low, pull-up은 유효한 high 제공

## Schmitt Trigger

- Noise가 있는 analog input이 단일 threshold 부근을 오가면 simple comparator의 출력이 반복 전환 가능
- Schmitt trigger는 rising input용 상단 threshold `VTH`와 falling input용 하단 threshold `VTL` 사용
- 두 threshold 사이의 immunity band가 작은 입력 변동에 따른 출력 전환 억제

## GPIO Input Data Register (IDR)

```c
uint32_t mask = 1UL << 7;
uint32_t input = (GPIOA->IDR & mask) == mask;
```

- `PA.7`의 bit를 mask로 추출해 Boolean 값으로 변환

```c
uint32_t input = (GPIOA->IDR & mask) >> 7;
```

- 같은 bit를 shift하여 `0` 또는 `1`로 읽는 방법

## GPIO Input Mode Register (MODER)

```c
GPIOA->MODER &= ~3UL;
```

- Pin `0`의 mode field를 `00`으로 설정해 input 선택

## GPIO Pull-Up/Pull-Down Register (PUPDR)

- 각 port의 `16`개 pin에 `2` bits씩 배정

```c
GPIOA->PUPDR &= ~3UL;
```

- Pin `0`에 pull-up 및 pull-down을 사용하지 않도록 `00` 설정
- `01`은 pull-up, `10`은 pull-down, `11`은 reserved
